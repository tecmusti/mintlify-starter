GET `/characters` returns the curated estudjo character catalog together with the characters you created yourself. A character is a reusable model image (with name, ethnicity, and description) you can pass in the `characters` field of an image [POST /generate](/api/generations/generate) request, for scenes that use characters.

**GET** `https://api.estudjo.com/characters`

<ParamField header="X-Api-Key" type="string" required>
  Your estudjo API key.
</ParamField>

<ParamField header="X-USER-LANG" type="string">
  2-letter ISO language code. Narrows **only the catalog** to characters for that language — your own characters are never filtered by it. Omit to skip language filtering.
</ParamField>

## Query parameters

<ParamField query="category" type="string">
  Category slug (e.g. `womens-clothing`). Narrows **both** the catalog and your own characters — your own character only appears if it is tagged with that category too. Omit to skip category filtering.
</ParamField>

## Example request

```bash
curl 'https://api.estudjo.com/characters?category=womens-clothing' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-USER-LANG: en'
```

<ResponseField name="data" type="array">
  <Expandable title="Character object">
    <ResponseField name="id" type="string">
      Character UUID. Pass it in the `characters` array of `POST /generate`.
    </ResponseField>

    <ResponseField name="image" type="string">
      URL of the character's primary image — always identical to `variants[0]`.
    </ResponseField>

    <ResponseField name="variants" type="string[]">
      Every image belonging to the character, as directly usable URLs. One entry for a plain character; several for a character built from an image grid.
    </ResponseField>

    <ResponseField name="name" type="string">
      Character name.
    </ResponseField>

    <ResponseField name="ethnicity" type="string">
      Character ethnicity.
    </ResponseField>

    <ResponseField name="description" type="string">
      Free-text description of the character.
    </ResponseField>

    <ResponseField name="type" type="string">
      `system` for a curated catalog character, `user` for one you created.
    </ResponseField>
  </Expandable>
</ResponseField>

<Info>
  This endpoint is not paginated — every visible character is returned. Your own characters come first (newest first), followed by the catalog in its curated order.
</Info>
