---
title: "Queue an Image, Video, or Text Generation"
sidebarTitle: "Generate"
description: "POST /generate — queue an AI image, video, or product-description generation. Pass a model and product image URL, and receive a task_id to poll for results."
---

POST `/generate` queues an AI generation job. The model you specify determines whether image, video, or text (product description) logic runs — check a model's `tool` in [GET /models](/api/models/list). The endpoint is asynchronous — it returns a `task_id` immediately; use [GET /status](/api/generations/status) to track completion, or pass a `callBackUrl` to be notified (see [Callbacks](/guides/callbacks)).

**POST** `https://api.estudjo.com/generate`

<ParamField header="X-Api-Key" type="string" required>
  Your estudjo API key.
</ParamField>

<Tabs>
  <Tab title="Image">
    ## Request body

    <ParamField body="model" type="string" required>
      Image model identifier (e.g. `estudjo/economic`). See [GET /models](/api/models/list).
    </ParamField>

    <ParamField body="aspect-ratio" type="string" required>
      Output aspect ratio (e.g. `1:1`).
    </ParamField>

    <ParamField body="resolution" type="string" required>
      Output resolution (e.g. `1K`).
    </ParamField>

    <ParamField body="image_urls" type="string[]" required>
      One or more publicly accessible product image URLs to use as the generation source. At least one is required; send several to give the model multiple reference images (support varies by model).
    </ParamField>

    <ParamField body="prompt" type="string">
      Full prompt override. When set, `category` and `scene` are not required, and your prompt is sent to the model **exactly as given**.
    </ParamField>

    <ParamField body="category" type="string">
      Category slug (e.g. `womens-clothing`). Required unless `prompt` is set; must be linked to the chosen scene.
    </ParamField>

    <ParamField body="scene" type="string">
      Scene UUID (`scene_id` from [GET /scenes](/api/scenes/list)). Required unless `prompt` is set.
    </ParamField>

    <ParamField body="characters" type="string[]">
      Character UUIDs from [GET /characters](/api/characters/list) and/or direct image URLs. Only used when the chosen scene supports characters — the `characters` count in [GET /scenes](/api/scenes/list) tells you how many a scene expects (`0` means it doesn't use them).
    </ParamField>

    <ParamField body="additional_data" type="object">
      Flat object of `string:string` pairs. Each entry is prepended to the prompt as a `"Title Case Key: Title Case Value"` line, in key order. Omit the field, pass `null`, or pass `{}` to add no extra data.
    </ParamField>

    <ParamField body="callBackUrl" type="string">
      URL that receives a `POST` with the result once the generation completes or fails. Best-effort, not retried. See [Callbacks](/guides/callbacks).
    </ParamField>

    ## Example request

    <CodeGroup>

    ```bash With scene
    curl -X POST https://api.estudjo.com/generate \
      -H 'X-Api-Key: YOUR_API_KEY' \
      -H 'Content-Type: application/json' \
      -d '{
        "model": "estudjo/economic",
        "category": "womens-clothing",
        "aspect-ratio": "1:1",
        "resolution": "1K",
        "scene": "59b4a671-1b90-453e-92c3-a28ceee177af",
        "image_urls": ["https://static.example.com/thumb/product-86713.jpg"],
        "additional_data": { "product_name": "White Long Dress" }
      }'
    ```

    ```bash With prompt
    curl -X POST https://api.estudjo.com/generate \
      -H 'X-Api-Key: YOUR_API_KEY' \
      -H 'Content-Type: application/json' \
      -d '{
        "model": "estudjo/economic",
        "aspect-ratio": "1:1",
        "resolution": "1K",
        "prompt": "Product on a marble table, soft morning light, minimalist studio",
        "image_urls": ["https://static.example.com/thumb/product-86713.jpg"]
      }'
    ```

    </CodeGroup>

    <Info>
      When `prompt` is set, no scene is looked up and the category/scene link isn't validated — the prompt is used verbatim.
    </Info>

  <Tab title="Video">
    ## Request body

    <ParamField body="model" type="string" required>
      Video model identifier (e.g. `estudjo/economic-video`).
    </ParamField>

    <ParamField body="aspect-ratio" type="string" required>
      Output aspect ratio (e.g. `1:1`).
    </ParamField>

    <ParamField body="resolution" type="string" required>
      Output resolution (e.g. `480P`).
    </ParamField>

    <ParamField body="duration" type="string" required>
      Clip duration in seconds, as a plain number string with no unit suffix (e.g. `"5"`). Must be one of the chosen model's `durations` from [GET /models](/api/models/list) — supported values differ per model.
    </ParamField>

    <ParamField body="image_urls" type="string[]" required>
      One or more publicly accessible product image URLs to use as the generation source. At least one is required.
    </ParamField>

    <ParamField body="prompt" type="string">
      Direct text prompt describing the desired video output. When `prompt` is present, `scene` is never consulted. Required if `scene` is not provided.
    </ParamField>

    <ParamField body="scene" type="string">
      Scene UUID (`scene_id` from [GET /scenes](/api/scenes/list)). Used only when `prompt` is absent — required if `prompt` is not supplied.
    </ParamField>

    <ParamField body="category" type="string">
      Category slug. Optional for video and never validated against the scene — but an unrecognized slug returns `400 invalid_input`.
    </ParamField>

    <ParamField body="callBackUrl" type="string">
      URL that receives a `POST` with the result once the generation completes or fails. Best-effort, not retried. See [Callbacks](/guides/callbacks).
    </ParamField>

    <Info>
      If `prompt` is present, `scene` is ignored entirely — the prompt takes full precedence.
    </Info>

    ## Example request

    ```bash
    curl -X POST https://api.estudjo.com/generate \
      -H 'X-Api-Key: YOUR_API_KEY' \
      -H 'Content-Type: application/json' \
      -d '{
        "model": "estudjo/economic-video",
        "aspect-ratio": "1:1",
        "resolution": "480P",
        "duration": "5",
        "prompt": "confident fashion model showcasing the outfit, slow cinematic camera pan",
        "image_urls": ["https://static.example.com/thumb/product-86713.jpg"]
      }'
    ```

  <Tab title="Text">
    Generates a product description (title, copy, attributes) from one or more product images.

    ## Request body

    <ParamField body="model" type="string" required>
      One of exactly three text model identifiers: `estudjo/economic-product-description`, `estudjo/plus-product-description`, or `estudjo/advanced-product-description`. Tier names alone (e.g. `economic`) are not accepted.
    </ParamField>

    <ParamField body="category" type="string" required>
      Category slug (e.g. `womens-clothing`). See [GET /categories](/api/categories/list).
    </ParamField>

    <ParamField body="image_urls" type="string[]" required>
      One or more publicly accessible product image URLs, sent to the model as vision input. At least one is required.
    </ParamField>

    <ParamField body="target_language" type="string" required>
      Language the content is generated in (e.g. `"Turkish"`, `"English"`).
    </ParamField>

    <ParamField body="brand_info" type="object">
      Steers tone and content toward your brand voice.

      <Expandable title="brand_info">
        <ParamField body="name" type="string">
          Brand name.
        </ParamField>

        <ParamField body="tone" type="string">
          Desired writing tone (e.g. `"Descriptive not interpretive. Neutral and calm."`).
        </ParamField>

        <ParamField body="about" type="string">
          Short description of the brand or store.
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="product" type="object">
      Any JSON object with product-specific facts (title, color, material, ...), merged into the prompt as-is. Omit it or send `{}` if there's nothing to add.
    </ParamField>

    <ParamField body="callBackUrl" type="string">
      URL that receives a `POST` with the result once the generation completes or fails. Best-effort, not retried. See [Callbacks](/guides/callbacks).
    </ParamField>

    ## Example request

    ```bash
    curl -X POST https://api.estudjo.com/generate \
      -H 'X-Api-Key: YOUR_API_KEY' \
      -H 'Content-Type: application/json' \
      -d '{
        "model": "estudjo/economic-product-description",
        "category": "womens-clothing",
        "image_urls": ["https://static.example.com/thumb/product-86713.jpg"],
        "target_language": "Turkish",
        "brand_info": {
          "name": "Lumen Atelier",
          "tone": "Descriptive not interpretive. Neutral and calm.",
          "about": "A boutique for minimalist everyday womenswear."
        },
        "product": { "title": "White Long Dress", "color": "white", "material": "denim, cotton" }
      }'
    ```

    ## Results

    When the generation completes, [GET /status](/api/generations/status) returns the output as files in `result_urls`:

    - **Two entries** (`.json` then `.md`) when the model's output was JSON-shaped — the common case. The `.json` is the raw structured output; the `.md` is a readable rendering of it (keys dropped, order preserved, embedded HTML converted to Markdown).
    - **One entry** (`.md` only) otherwise.

    ```json
    {
      "success": true,
      "data": {
        "status": "completed",
        "result_urls": [
          "https://files.estudjo.com/generations/9a9b30f5e0db85b69497c9f9e8fbf5f2/1279641152bf9ad2b19b13cd4abc99dc.json",
          "https://files.estudjo.com/generations/9a9b30f5e0db85b69497c9f9e8fbf5f2/f496301660d2ec000e00bf1249c5c810.md"
        ]
      }
    }
    ```

    <Warning>
      Text generations never return `502 provider_error` from `POST /generate`. The model call runs in the background after `queued` is returned (it can take close to a minute), so a provider failure only appears later as `"status": "failed"` with an `error_message` in `GET /status` — or in your callback.
    </Warning>

    ## Text-specific errors

    | Code | HTTP | Cause |
    | --- | --- | --- |
    | `invalid_input` | 400 | Missing required field, unrecognized `category` slug, or no pricing configured for this model |
    | `not_found` | 404 | `model` is not one of the three text model identifiers above |
    | `insufficient_credits` | 402 | Your credit balance is too low to queue this job |

## Response

```json
{
  "success": true,
  "data": {
    "status": "queued",
    "task_id": "6bfd652d4c31261ffb8ed3424ac2775e"
  }
}
```

<ResponseField name="success" type="boolean">
  `true` when the request was accepted and the job was queued.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="status" type="string">
      Always `"queued"` on a successful response — the job has been accepted and is waiting to run.
    </ResponseField>

    <ResponseField name="task_id" type="string">
      Unique identifier for this generation job. Save this value and pass it to [GET /status](/api/generations/status) to poll for results.
    </ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Code | HTTP | Cause |
| --- | --- | --- |
| `invalid_input` | 400 | Missing required field, empty `image_urls`, neither `prompt` nor `scene` given (or, for image, `category` missing without `prompt`), invalid `aspect-ratio`/`resolution`/`duration`, category not linked to scene, no pricing for the chosen options, or `additional_data` values are not flat strings |
| `not_found` | 404 | Unknown model, or the specified scene doesn't exist or doesn't belong to your account |
| `insufficient_credits` | 402 | Your credit balance is too low to queue this job |
| `provider_error` | 502 | The upstream AI provider returned an error (image and video only). For video generations, this can also indicate that the merged prompt (scene text + additional data) exceeded the provider's length limit |
