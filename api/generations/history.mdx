GET `/generations` returns a paginated list of every generation on your account — one item per individual attempt — with its status, the request it was made with, output URLs, and credit ledger entries. Use it to build dashboards, audit credit usage, or let users browse past results. To see an original generation grouped with its regenerations, use [GET /generations/jobs](/api/generations/jobs).

**GET** `https://api.estudjo.com/generations`

<ParamField header="X-Api-Key" type="string" required>
  Your estudjo API key.
</ParamField>

---

## Query parameters

<ParamField query="page" type="integer">
  Page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="limit" type="integer">
  Number of results per page. Accepts `1`–`250`. Defaults to `250`.
</ParamField>

<ParamField query="status" type="string">
  Filter to a single status: `pending`, `completed`, or `failed`. Omit to return all statuses.
</ParamField>

<ParamField query="tool" type="string">
  Filter to a single tool: `image`, `video`, or `text`. Omit to return all tools.
</ParamField>

<ParamField query="model" type="string">
  Filter to a single model, using the same identifier as `model` in `POST /generate` (e.g. `estudjo/economic`). URL-encode the slash as `%2F`. An unknown model simply returns no results.
</ParamField>

## Example request

```bash
curl 'https://api.estudjo.com/generations?status=completed&tool=image&limit=20&page=1' \
  -H 'X-Api-Key: YOUR_API_KEY'
```

## Credit log types

Each generation produces one or more `credits_logs` entries that trace the full lifecycle of its credit charge.

| Type | Meaning |
| --- | --- |
| `reserve` | Credits held against your balance when the job was queued |
| `spend` | Charge confirmed — credits were consumed after a successful generation |
| `release` | Credits refunded — the reserved amount was returned to your balance |

**Reading the ledger:**

- A single `reserve` entry with no follow-up → the generation is still **pending**.
- `reserve` \+ `spend` → generation **completed** and credits were charged.
- `reserve` \+ `release` → generation **failed** and the reserved credits were refunded.

## Errors

| Code | HTTP | Cause |
| --- | --- | --- |
| `invalid_input` | 400 | `page` is not a positive integer, `limit` is outside `1`–`250`, `status` is not one of `pending`/`completed`/`failed`, or `tool` is not one of `image`/`video`/`text` |
