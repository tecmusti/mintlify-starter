---
title: "List Scenes with GET /scenes Endpoint"
sidebarTitle: "List Scenes"
description: "GET /scenes — list predefined and user-created scenes. Filter by category, model, or type. Returns scene_id, name, and type for each result."
---

GET /scenes returns both predefined (estudjo-provided) and user-created scenes. Some scenes come in several **variants** (for example different poses in the same setting); each variant is listed as its own item with its own `scene_id`, so you can pass it straight to `POST /generate`. Only `name`, `scene_id`, `type`, `tool`, `url`, `preview_image`, `previews`, and `characters` are returned here. Use [GET /scenes/\{scene_id\}](/api/scenes/get) for full details of your own scenes.

## Endpoint

<ParamField header="X-Api-Key" type="string" required>
  Your API key.
</ParamField>

```text
GET https://api.estudjo.com/scenes
```

## Query Parameters

<ParamField query="category" type="string">
  Filter by category slug (e.g. `womens-clothing`). An unknown slug returns `400 invalid_input`.
</ParamField>

<ParamField query="model" type="string">
  Filter by full model identifier (e.g. `estudjo/economic-video`). URL-encode the slash as `%2F`. An unknown model returns `400 invalid_input`.
</ParamField>

<ParamField query="tool" type="string">
  Only scenes for this kind of generation: `image`, `video`, `text`, or `scrape`. Use `image` for scenes to pass to an image generation and `video` for a video generation. An unknown value returns `400 invalid_input`.
</ParamField>

<ParamField query="lang" type="string">
  2-letter language code (e.g. `tr`). When set, `name` is returned as a single string in that language instead of the full language map, and each `url` uses that language. If a scene has no name in that language (or the code isn't a known language), English is used for both. If `lang` is not set, the `X-USER-LANG` header is used the same way.
</ParamField>

<ParamField query="type" type="string">
  Pass `user_created` to list only your own scenes. Any other value returns `400`.
</ParamField>

<ParamField query="page" type="integer">
  Page number. Defaults to `1`.
</ParamField>

<ParamField query="limit" type="integer">
  Number of results per page. Accepted range: `1`–`250`. Defaults to `250`.
</ParamField>

## Example Request

```bash
curl 'https://api.estudjo.com/scenes?category=womens-clothing&tool=image&limit=50' \
  -H 'X-Api-Key: YOUR_API_KEY'
```

### 200 — Success

```json
  "data": {
    "scenes": [
      {
        "name": { "en": "Bedroom Morning Routine – Seated On Bed", "tr": "Sabah Rutini – Yatakta Oturuş" },
        "scene_id": "54fde974-7b3a-4cda-bec3-b82aed8ddb32",
        "type": "predefined",
        "tool": "video",
        "url": "https://www.estudjo.com/en/scenes/video-bedroom-morning-routine",
        "preview_image": "https://files.estudjo.com/assets/fefda6be-52ed-4dfa-b688-c1788c9803d1.jpeg",
        "previews": [
          {
            "category": "lingerie",
            "model": "estudjo/economic-video",
            "image": "https://files.estudjo.com/assets/fefda6be-52ed-4dfa-b688-c1788c9803d1.jpeg",
            "video": "https://files.estudjo.com/assets/002fbef1-7933-4253-bb21-24c846c91552.mp4"
          }
        ],
        "characters": 1
      },
      {
        "name": { "en": "Grand Historic Interior" },
        "scene_id": "59b4a671-1b90-453e-92c3-a28ceee177af",
        "type": "user_created",
        "tool": "image",
        "preview_image": null,
        "previews": [],
        "characters": 0
      }
    ],
    "page": 1,
    "per_page": 250,
    "total": 2
  }
}
```

<ResponseField name="scenes" type="array">
  Array of scene objects matching your query.

  <Expandable title="Scene object">
    <ResponseField name="name" type="object | string">
      A single string when `lang` or `X-USER-LANG` is given; otherwise a map of language code → translated name (e.g. `{ "en": "...", "tr": "..." }`). For a scene with several variants it reads `"Scene name – Variant name"`; for a single-variant scene it is just the scene name. Omitted entirely for a scene with no translations (rare).
    </ResponseField>

    <ResponseField name="scene_id" type="string">
      UUID identifying this scene variant. Pass it as `scene` in `POST /generate`, and use it in the scene detail, update, and delete endpoints.
    </ResponseField>

    <ResponseField name="type" type="string">
      Either `predefined` (estudjo-provided) or `user_created` (owned by your account).
    </ResponseField>

    <ResponseField name="tool" type="string">
      Which kind of generation the scene is for: `image`, `video`, `text`, or `scrape`.
    </ResponseField>

    <ResponseField name="url" type="string">
      Link to the scene's page on estudjo.com, in the `lang` language (English by default). Present only for `predefined` scenes.
    </ResponseField>

    <ResponseField name="preview_image" type="string | null">
      URL of the main preview image: the first preview's `image`, or the scene's own preview image when the variant has no previews. `null` if neither exists.
    </ResponseField>

    <ResponseField name="previews" type="array">
      Example outputs for the scene, in display order. `[]` when there are none. Narrowed by the `category` query parameter (but not by `model`).

      <Expandable title="Preview object">
        <ResponseField name="image" type="string">
          Preview image URL.
        </ResponseField>

        <ResponseField name="video" type="string">
          Preview video URL. Present only when the preview has a video (video scenes); omitted otherwise.
        </ResponseField>

        <ResponseField name="category" type="string">
          Category slug the preview was made for.
        </ResponseField>

        <ResponseField name="model" type="string">
          Model identifier the preview was made with.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="characters" type="integer">
      How many character images the scene expects in the `characters` field of [POST /generate](/api/generations/generate). `0` means the scene doesn't use characters.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="page" type="integer">
  The current page number returned.
</ResponseField>

<ResponseField name="per_page" type="integer">
  The number of results per page used for this response.
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of items (scene variants) matching the query across all pages.
</ResponseField>

<Info>
  Requesting a page number beyond the last page returns an empty `scenes` array — `total` is still populated with the full count. This is not treated as an error.
</Info>

## Errors

| Code | HTTP | Cause |
| --- | --- | --- |
| `invalid_input` | 400 | `page` is not a positive integer, `limit` is outside `1`–`250`, `type` is not `user_created`, or `category` / `model` / `tool` doesn't match a known category, model, or tool. |
