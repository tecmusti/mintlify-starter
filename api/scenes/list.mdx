---
title: "List Scenes with GET /scenes Endpoint"
sidebarTitle: "List Scenes"
description: "GET /scenes — list predefined and user-created scenes. Filter by category, model, or type. Returns scene_id, name, and type for each result."
---

GET /scenes returns both predefined (estudjo-provided) and user-created scenes. Only `name`, `scene_id`, `type`, `preview_image`, `previews`, and `characters` are returned here — use [GET /scenes/\{scene_id\}](/api/scenes/get) for full details of your own scenes.

## Endpoint

<ParamField header="X-Api-Key" type="string" required>
  Your API key.
</ParamField>

```text
GET https://api.estudjo.com/scenes
```

## Query Parameters

<ParamField query="category" type="string">
  Filter by category slug (e.g. `womens-clothing`).
</ParamField>

<ParamField query="model" type="string">
  Filter by full model identifier (e.g. `estudjo/economic-video`). URL-encode the slash as `%2F`.
</ParamField>

<ParamField query="type" type="string">
  Pass `user_created` to list only your own scenes. Any other value returns `400`.
</ParamField>

<ParamField query="page" type="integer">
  Page number. Defaults to `1`.
</ParamField>

<ParamField query="limit" type="integer">
  Number of results per page. Accepted range: `1`–`250`. Defaults to `250`.
</ParamField>

## Example Request

```bash
curl 'https://api.estudjo.com/scenes?category=womens-clothing&type=user_created&limit=50' \
  -H 'X-Api-Key: YOUR_API_KEY'
```

```json
        "type": "predefined",
        "preview_image": "https://files.estudjo.com/scene-previews/54fde974-7b3a-4cda-bec3-b82aed8ddb32/main.jpg",

            "thumbnail": "https://files.estudjo.com/scene-previews/54fde974-7b3a-4cda-bec3-b82aed8ddb32/main.jpg",

```

<ResponseField name="scenes" type="array">
  Array of scene objects matching your query.

  <Expandable title="Scene object">
    <ResponseField name="name" type="object">
      Map of language code → translated name (e.g. `{ "en": "...", "tr": "..." }`). Omitted entirely for a scene with no translations (rare).
    </ResponseField>

    <ResponseField name="scene_id" type="string">
      UUID uniquely identifying the scene.
    </ResponseField>

    <ResponseField name="type" type="string">
      Either `predefined` (estudjo-provided) or `user_created` (owned by your account).
    </ResponseField>

    <ResponseField name="preview_image" type="string | null">
      URL of the scene's main preview image, or `null` if it has none.
    </ResponseField>

    <ResponseField name="previews" type="array">
      Example outputs for the scene, in display order. `[]` when there are none. Narrowed by the `category` query parameter (but not by `model`).

      <Expandable title="Preview object">
        <ResponseField name="thumbnail" type="string">
          Thumbnail URL.
        </ResponseField>

        <ResponseField name="url" type="string">
          Full-size file URL. May point to a video in the future, not only images.
        </ResponseField>

        <ResponseField name="category" type="string">
          Category slug the preview was made for.
        </ResponseField>

        <ResponseField name="model" type="string">
          Model identifier the preview was made with.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="characters" type="integer">
      How many character images the scene expects in the `characters` field of [POST /generate](/api/generations/generate). `0` means the scene doesn't use characters.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="page" type="integer">
  The current page number returned.
</ResponseField>

<ResponseField name="per_page" type="integer">
  The number of results per page used for this response.
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of scenes matching the query across all pages.
</ResponseField>

<Info>
  Requesting a page number beyond the last page returns an empty `scenes` array — `total` is still populated with the full count. This is not treated as an error.
</Info>

## Errors

| Code | HTTP | Cause |
| --- | --- | --- |
| `invalid_input` | 400 | `page` is not a positive integer, `limit` is outside `1`–`250`, or `type` is not `user_created`. |
