---
title: "Update a Scene via PUT /scenes/{scene_id}"
sidebarTitle: "Update Scene"
description: "PUT /scenes/{scene_id} — update the name, description, prompt, or character count of a user-created estudjo scene. Models and categories cannot be changed after creation."
---

Update the `name`, `description`, `prompt`, or `characters` of a scene you own. The scene must be `user_created` and not archived. Models and categories are fixed at creation and cannot be modified — submit a new scene via [POST /scenes](/api/scenes/create) if you need different associations.

## Endpoint

<ParamField header="X-Api-Key" type="string" required>
  Your API key.
</ParamField>

```text
PUT https://api.estudjo.com/scenes/{scene_id}
```

## Path Parameters

<ParamField path="scene_id" type="string" required>
  UUID of the user-created scene to update.
</ParamField>

## Request Body

<ParamField body="name" type="string" required>
  Updated display name for the scene. 5–255 characters.
</ParamField>

<ParamField body="prompt" type="string" required>
  Updated prompt text for the scene. Cannot be empty.
</ParamField>

<ParamField body="description" type="string">
  Updated short description. Optional, maximum 255 characters.
</ParamField>

<ParamField body="characters" default="0" type="integer">
  How many character images the scene expects in [POST /generate](/api/generations/generate). Optional, defaults to `0` when omitted — so send the current value if you want to keep it. Must not be negative.
</ParamField>

<Info>
  `models`, `categories`, and `scene_id` cannot be changed. The `scene_id` assigned at creation is permanent.
</Info>

## Example Request

```bash
curl -X PUT https://api.estudjo.com/scenes/7c1e2f4a-9b3d-4e5f-8a6b-1c2d3e4f5a6b \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"name": "Bright Minimalist Studio v2", "prompt": "Updated prompt text.", "characters": 1}'
```

## Response

### 200 — Success

```json
{ "success": true, "data": { "name": "Bright Minimalist Studio v2", "scene_id": "7c1e2f4a-9b3d-4e5f-8a6b-1c2d3e4f5a6b", "type": "user_created", "preview_image": null, "characters": 1 } }
```

<ResponseField name="name" type="string">
  The updated display name of the scene.
</ResponseField>

<ResponseField name="scene_id" type="string">
  UUID of the scene. Unchanged.
</ResponseField>

<ResponseField name="type" type="string">
  Always `user_created` for scenes you own.
</ResponseField>

<ResponseField name="preview_image" type="string | null">
  URL of the scene's preview image, or `null` if it has none.
</ResponseField>

<ResponseField name="characters" type="integer">
  The character count now stored for the scene.
</ResponseField>

## Errors

| Code | HTTP | Cause |
| --- | --- | --- |
| `invalid_input` | 400 | `name` is fewer than 5 or more than 255 characters, `description` is longer than 255 characters, `prompt` is empty, `characters` is negative, or other validation failed (same rules as [POST /scenes](/api/scenes/create)). |
| `not_found` | 404 | The scene doesn't exist, belongs to another account, is predefined, is archived, or `scene_id` is not a valid UUID. All cases are intentionally indistinguishable. |
