estudjo is a REST API that turns your product photos into studio-quality marketing images, short cinematic videos, and ready-to-publish product descriptions. Instead of expensive photo shoots or manual copywriting, you send your product image URLs along with a scene or your own prompt, and estudjo's AI models handle the rest — returning permanent, ready-to-use output URLs you can plug straight into your storefront, ads, or CMS.

## How it works

<Steps>
  <Step title="Submit a generation request">
    Send a `POST /generate` request with your product image URLs and the model you want to use. For images and videos, add a scene that defines the visual style — or your own `prompt`. The model decides whether an image, video, or text generation runs.
  </Step>
  <Step title="Receive a task ID">
    The API responds immediately with a `task_id`. Generation happens asynchronously, so your request never blocks.
  </Step>
  <Step title="Track progress">
    Call `GET /status?taskId={task_id}` every few seconds until `status` is `completed` or `failed` — or pass a `callBackUrl` and let estudjo POST the result to you.
  </Step>
  <Step title="Use your results">
    Read the `result_urls` array: images and videos for visual generations, a `.json` + `.md` pair for product descriptions. These are permanent, public-read URLs ready to use anywhere.
  </Step>
</Steps>

<Note>
  All endpoints require an `X-Api-Key` header except `GET /healthz`. See [Authentication](/authentication) to get a key.
</Note>

## Public API surface

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | [`/healthz`](/api/health/healthz) | Health check (no API key required) |
| `POST` | [`/api-keys`](/api/api-keys/create) | Create a new API key |
| `GET` | [`/api-keys`](/api/api-keys/list) | List all API keys on your account |
| `DELETE` | [`/api-keys/{key_id}`](/api/api-keys/revoke) | Revoke an API key |
| `GET` | [`/wallet/balance`](/api/wallet/balance) | Retrieve your current credit balance |
| `GET` | [`/models`](/api/models/list) | List models, their options, and pricing |
| `GET` | [`/categories`](/api/categories/list) | List product categories and suggested models |
| `POST` | [`/generate`](/api/generations/generate) | Queue an image, video, or text generation |
| `GET` | [`/status`](/api/generations/status) | Poll a generation's status by `taskId` |
| `GET` | [`/generations`](/api/generations/history) | List past generations with their credit ledger |
| `GET` | [`/scenes`](/api/scenes/list) | List predefined and your own scenes |
| `GET` | [`/scenes/{scene_id}`](/api/scenes/get) | Retrieve one of your scenes |
| `POST` | [`/scenes`](/api/scenes/create) | Create a custom scene |
| `PUT` | [`/scenes/{scene_id}`](/api/scenes/update) | Update one of your scenes |
| `DELETE` | [`/scenes/{scene_id}`](/api/scenes/delete) | Archive one of your scenes |
| `GET` | [`/characters`](/api/characters/list) | List curated and your own characters |
